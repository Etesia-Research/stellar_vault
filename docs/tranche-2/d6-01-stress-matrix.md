# D6-01 stress matrix

This record shows the stress scenarios run against the Etesia vault and keeper, each with its expected result, actual result and evidence. It supports the D6 measure "stress scenarios executed with documented results; invalid executions rejected onchain". All testnet receipts come from the pre-reset testnet deployment (manifest `deploy/testnet/pre-2026-12-16-reset.json`, SHA-256 `cfa30d48…2220`), and the archived XDR is the record.

Vault paths and test names refer to the [vault repository at `5807b85`](https://github.com/Etesia-Research/stellar_vault/tree/5807b8535ed26224e7e6155ac65a6e4581d81752). Quant test names refer to `etesia-quant` at `1e8d2aa`.
